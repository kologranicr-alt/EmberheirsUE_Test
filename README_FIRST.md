# EMBERHEIRS UE DOCUMENTATION PACK

Copy the contents of this folder into the ROOT of `EmberheirsUE_Test` so that `AGENTS.md` sits beside the `.uproject` file and the `docs` folder is directly under the project root.

Expected layout:

EmberheirsUE_Test/
  AGENTS.md
  CURRENT_PHASE.md
  README_FIRST.md
  docs/
  Config/
  Content/
  Source/
  EmberheirsUE_Test.uproject

Before giving Codex or Aura a substantial task, instruct it to read `AGENTS.md`, `CURRENT_PHASE.md`, and the relevant docs first.

This pack intentionally documents the long-term Emberheirs direction while restricting the current Unreal work to a proof of concept. It does not authorize migration of the existing Godot production project.
